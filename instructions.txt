## Performance Considerations

1. OpenAI embeddings may be more expensive than local models but could provide better accuracy

2. The GPT-4 selector adds an API call for each product, which increases cost and time
   - Consider setting a similarity threshold to only use GPT-4 for ambiguous cases
   - Run a smaller test set first to validate the approach

3. You can add caching to the OpenAI API calls to avoid redundant requests

4. Note that in our previous testing, upgrading from 'all-MiniLM-L6-v2' to 'all-mpnet-base-v2' improved embedding quality, so this should be included in our comparison as a potential strong baseline
