# Product Clustering Action Plan

## 1. Objective
- Group ~10,000 SKUs into clusters of 5-20 similar products
- Achieve ~80% precision on spot-check sample
- Deliver working code runnable on laptop (16GB RAM)
- Output format: clusters.json mapping cluster_id → [sku_ids...]

## 2. Implementation Plan

### 2.1 Data Preparation [Done]
- Leverage existing data processing pipeline from src/data_processing.py
- Update preprocessing to focus on product similarity rather than USDA mapping:
  - Implemented text normalization (lowercase, strip punctuation, standardize whitespace)
  - Simplified the approach by focusing directly on product descriptions
  - Removed attribute extraction to improve clustering quality
- Created data preprocessing pipeline that directly processes raw product descriptions

### 2.2 Feature Engineering [Done]
- Utilize existing embedding infrastructure (src/VectorDB/localEmbedder.py)
- Continue using the 'all-mpnet-base-v2' model from sentence-transformers
- Create a weighted feature vector combining:
  - Text embeddings from product descriptions (primary feature)
  - Brand information (if available)
  - Size/quantity features
  - Price range indicators (if available)
- Save embeddings to numpy array for reproducibility

### 2.3 Clustering Implementation [Done]
- Created a new clustering.py module
- Implemented HDBSCAN clustering with initial parameters:
  - min_cluster_size=5
  - min_samples=3
  - metric='euclidean'
- Enhanced with improved_clustering.py module for optimized parameters:
  - min_cluster_size=3 (for more granular clusters)
  - min_samples=2 (for more focused product groupings)
  - Added test mode capability for rapid parameter tuning
- Implemented helper functions to analyze cluster statistics

### 2.4 Outlier Handling [Done]
- Identified unclustered products (assigned to noise cluster -1 by HDBSCAN)
- Exported these to a separate file (unclustered.csv) for manual review
- Implemented optimized clustering parameters to achieve better balance between precision and recall
- Added capability to run clustering on subsets of data for faster experimentation embeddings for future re-clustering

### 2.5 Evaluation [Done]
- Created an evaluation module to assess cluster quality
- Implemented metrics including:
  - Cluster coherence (intra-cluster similarity using cosine similarity)
  - Cluster size distribution analysis
  - Automated quality assessment with configurable thresholds
  - Manual review capability through sample cluster display
- Established target precision of 80% with automated verification
- Optimized clustering parameters to improve quality metrics

### 2.6 Export & Visualization [Done]
- Export clusters.json with mapping of cluster_id → [sku_ids...]
- Generate cluster_size_hist.png for distribution visualization
- Create a simple HTML visualization of largest clusters

### 3.2 Leveraging Existing Codebase
- Reuse the ProductEmbedder class for generating embeddings

### 3.3 Key Improvements Over Original Plan

- Potential to incorporate CrossEncoder for boundary case validation
- Ability to use weighted features instead of just text embeddings
- Infrastructure for both local and OpenAI embeddings already in place

## 5. Parameter Configuration

param | default | tuning tip
------|---------|------------
min_cluster_size | 5 | raise to 8 if clusters too small
min_samples | 3 | controls sensitivity to noise
metric | "euclidean" | cosine also works well with embeddings
embed_model | all-mpnet-base-v2 | already using a strong model

## 6. CLI Example

```bash
# Run the clustering pipeline
python clustering.py --min_cluster_size 5 --min_samples 3 --output clusters.json

# Evaluate cluster quality
python evaluation.py --clusters clusters.json --sample_size 15
```
